### CLI COMMANDS 

This is the list of CLI Commands and git Commands
* `pwd` - print working directory
* `ls` - list
* `cd folder` - move into a folder
* `clear` - Cleans up your terminal screen 
* `mkdir folder-name` - Creates a new folder 
* `touch file.html` - Creates a new empty file 
* `code` . - Opens current folder in VS Code
* `rm file.html` - Deletes a file permanently 
* `rm -rf folder/` - Deletes a folder and everything inside 
* `cd ~` - Jump straight to your ome directory from anywhere 
* `cd ..` - Go up one folder level 
* `mkdir -p a/b` - Create nested folders in one command 
* `git init` - initialise git
* `git status` - shows the state of the git
* `git config` - confiure the git user
* `git add filename.html` - to add new updates or changes to the file
* `git commmit -m` - commit your changes with a message
